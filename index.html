How it works: Island = THREE.MarchingCubes metaballs (48³ field, ~20k polys). Baseplate = sand box with stud grid texture. Ocean = 200×200 plane (40k verts) displaced in vertex shader with 4 Gerstner waves + 8 ripple slots. Floor = displaced plane with dunes. Buoys sample wave height on CPU for true floating.

Water level moves the ocean plane; foam appears when depth < 2.5m or at wave crests. All dependency-free, single file, GitHub Pages ready.
