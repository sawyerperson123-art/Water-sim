# Drift — Water simulation

A lightweight, dependency-free interactive water surface for GitHub Pages.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

In the repository settings, choose **Pages → Deploy from a branch**, select `main` and the root folder. The site is a single static HTML file and needs no build step.

Interact by dragging or tapping the surface. Use the controls to change ripple force, flow speed, trigger rain, or reset the scene.
